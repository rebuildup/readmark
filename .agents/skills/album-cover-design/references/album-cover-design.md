# Album Cover Design References

Last reviewed: 2026-09-14

この reference set は album cover を一つの aesthetic grammar へ固定するためではなく、**release truth / primary visual proposition / scale behavior / release-family continuity / medium translation** を比較するために使う。

current platform guidance は delivery / policy constraint の evidence であり、visual style の source of truth ではない。

## Current platform / delivery context

### Spotify — Cover art requirements

https://support.spotify.com/jp/artists/article/cover-art-requirements/

Observe:

- square release artwork が current delivery unit であること
- high-resolution source / raster quality
- sRGB / final file behavior
- platform requirement と design decision の境界

Useful for:

- final delivery QA
- authoring file ではなく delivered raster を確認する理由

Do not copy as universal rule:

- pixel minimum / maximum
- file format requirement
- Spotify固有の ingest behavior

### Apple Music for Artists — Album cover art on Apple Music

https://artists.apple.com/support/1120-cover-art

Observe:

- cover artwork の accuracy / truthfulness
- artist / release title text は許容されるが、無関係な追加情報は artwork role ではないこと
- misleading / generic artwork の禁止
- unintended blur / pixelation / crop と intentional treatment の区別
- retailer / pricing / brand / date / barcode / rights / explicit-status 等の policy boundary

Useful for:

- release truth
- artwork text と metadata の責務
- final policy review

Do not copy as universal rule:

- Apple固有の file size / metadata policy
- Apple向け禁止事項を全媒体の composition law にすること

### Apple Music Style Guide — Artwork

https://help.apple.com/itc/musicstyleguide/en.lproj/static.html

Observe:

- original cover art を優先する accuracy principle
- generic template と release-specific artwork の違い
- artwork / title / artist metadata の consistency
- quality issue と deliberate visual treatment の違い

Useful for:

- catalog / reissue / distributor context
- release metadata と cover identity の整合確認

### Bandcamp — Design tutorial

https://get.bandcamp.help/en/articles/15263106-bandcamp-design-tutorial

Observe:

- album art が search / tag / Discover 等の discovery surface に直接現れること
- album art と artist page background / color customization が別責務であること
- physical booklet など別 format の artwork を square discovery image に無思考で流用できないこと

Useful for:

- artwork が standalone object ではなく surrounding browse context に置かれることの確認
- cover master と artist-page / campaign presentation の境界

Do not copy as universal rule:

- Bandcamp固有の page skinning / image dimensions

## Canonical historical references

### Cooper Hewitt — Josef Albers, `Persuasive Percussion`

https://www.cooperhewitt.org/2013/11/21/alberss-album-cover/

Observe:

- geometric abstraction が音楽の rhythm / syncopation / tonal character と対応する方法
- performer portrait や literal scene がなくても release-specific identity が成立すること
- repeated geometric vocabulary の中で controlled irregularity が focal behavior を作ること

Useful for:

- abstraction-led cover
- music → visual structure の翻訳

Avoid copying:

- dot motif
- Albers固有の color / grid language

### Cooper Hewitt — Laini Abernathy, `Sound`

https://www.cooperhewitt.org/2021/02/10/laini-abernathy/

Observe:

- photograph / concentric structure / custom lettering の一体化
- portrait が単なる artist photo ではなく composition の visual source になる方法
- cultural / movement context と graphic form の関係

Useful for:

- portrait + graphic-system integration
- identity / context が cover form に影響する例

Avoid copying:

- exact lettering
- Black Arts Movement の文脈を無関係な release へ aesthetic として移植すること

### MoMA — Hipgnosis / George Hardie, `The Dark Side of the Moon`

https://www.moma.org/collection/works/185416

Observe:

- performer portrait や title text を front cover の中心に置かない iconic-symbol model
- simple silhouette が large / small scale の両方で強い identity anchor になり得ること
- historical artwork の context / authorship

Useful for:

- symbol-led release identity
- textless / low-text cover を検討する比較点

Avoid copying:

- prism / spectrum motif
- Hipgnosis を「conceptual album cover」の universal style とみなすこと

## Production references

### Pentagram — `First Two Pages of Frankenstein`

https://www.pentagram.com/work/first-two-pages-of-frankenstein/story

Observe:

- ordinary / offbeat source photograph を texture / color processing によって album tone へ接続する方法
- one image が cover だけでなく visual identity / packaging / promotion の source になる関係
- strange image の novelty ではなく、release の emotional / conceptual context と image choice の関係

Useful for:

- source-photography-led cover
- primary cover → campaign extension

Avoid copying:

- snapshot aesthetic
- specific texture / color treatment

### Pentagram — Lake `Four`

https://www.pentagram.com/work/lake

Observe:

- historical album series の recurring motif を50年後の release で再利用する方法
- motif / illustrator / conceptual joke を保ちながら、新作として別の image を成立させる relationship
- nostalgia と continuity が release context によって正当化されていること

Useful for:

- long-running series
- anniversary / comeback / catalog continuity

Avoid copying:

- animal/flood motif
- continuity が不要な新規 artist に legacy grammar を作ること

### Studio Moross — Jade Bird, `Who Wants to Talk About Love`

https://www.studiomoross.com/work/jade-bird-wwttal

Observe:

- road-trip photography、type、texture を同じ release concept へ統合する方法
- album artwork / singles / logo / packaging / poster が related family だが、同一 canvas の反復ではないこと
- physical halftone / textured paper / label treatment が medium-specific extension になっていること

Useful for:

- release family
- photographic memory / ephemera concept
- digital master と physical translation の比較

Avoid copying:

- road-trip aesthetic
- mid-century ephemera treatment

### Studio Moross — Jade Bird, `Burn The Hard Drive`

https://www.studiomoross.com/work/burn-the-hard-drive

Observe:

- erase / delete / data-ghost concept が video、campaign artwork、print で異なる technique へ翻訳されること
- physical sleeve では die-cut が conceptual operation 自体を担うこと
- medium-specific technique を literal identity clone にせず concept を保持する方法

Useful for:

- primary visual concept → materially different media execution
- physical effect が digital image とどう違うかを考える reference

Avoid copying:

- glitch / datamosh / cutout を technology-themed music の default にすること

### Studio Moross — Myles Smith, `My Mess, My Heart, My Life`

https://www.studiomoross.com/work/my-mess-my-heart-my-life

Observe:

- artist journey / vulnerability という premise と analogue image-editing process の接続
- photography を完成素材として使うのではなく、processing method 自体が visual through-line になること
- cover / campaign / press / physical packaging 間の identity relationship

Useful for:

- process-led image language
- portrait/photo family を単なる repeated shoot image にしない方法

Avoid copying:

- analogue imperfection を「authentic music」の generic effect にすること

## Cross-reference comparison prompts

reference を開いたら、最低限次を比較する。

| Axis | Questions |
| --- | --- |
| release proposition | 何を一つの記憶点にしているか |
| representation | portrait / object / illustration / abstraction / type / archive のどれが ownership を持つか |
| text | artist/title text が identity に必要か、metadata と何を分担するか |
| scale | small tile と large view で primary / secondary read がどう変わるか |
| material | texture/process は concept を担うか、decorative effect か |
| family | singles / album / reissue で何を保持し何を変えているか |
| medium | digital / physical / poster / motion で concept はどう翻訳されるか |
| truth | release / performer / edition / rights を誤認させないか |

## Translation reminders

- reference 固有の artwork asset、photo、illustration、typeface、logo をコピーしない。
- visual vocabulary ではなく **relationship / decision / trade-off** を移植する。
- square は current streaming delivery evidence として扱い、すべての音楽graphicを square に固定しない。
- small-size recognition と visual simplicity を同義にしない。
- typography の有無を ideology にしない。metadata context と cover proposition から決める。
- physical process が強い reference は、digital raster で何が失われるかを必ず比較する。
- platform guidance は freshness を再確認する。仕様値や禁止事項が変わった場合、current target の guidance を優先する。
