# Brand Mark References

Last reviewed: 2026-09-15

この reference set は mark の具体形状を模倣するためではなく、**role / recognition / optical correction / scale / polarity / lockup / reproduction** の判断を比較するために使う。

一つの source family だけから一般化しない。primary/current brand system と、複数 studio の production identity を横断して観察する。

## Primary / current mark systems

### GitHub Brand Toolkit — Logo

- https://brand.github.com/foundations/logo
- Observe:
  - standalone Invertocat と wordmark lockup の役割分担
  - brand context が既にある場合と corporate/external context での usage 差
  - product lockup と event/sub-brand の責務分離
  - contrast / background / rearrangement / distortion の restrictions
  - deprecated mark を明示して current approved asset を運用する governance
- Useful for:
  - symbol と lockup を常に一体化しない context policy
  - ownership / trademark / approved-master constraints
- Avoid copying:
  - GitHub 固有の pictogram、lockup geometry、clear-space 値、color

### GitHub Brand Toolkit — Co-branding

- https://brand.github.com/brand-identity/cobranding
- Observe:
  -異なる logo を「同じ数値サイズ」にせず、width / height と optical center を見ながら balance する考え方
  - relationship / ownership を spacing と prominence で誤認させないこと
- Useful for:
  - partner / sponsor / parent-child lockup の optical comparison
- Avoid copying:
  - GitHub 固有 template や approval process を他 brand の geometry rule にすること

### IBM Design Language — 8-Bar

- https://www.ibm.com/design/language/ibm-logos/8-bar/
- Observe:
  - positive では黒 stripe を白 stripe より物理的に太くし、知覚上近い重量へ補正していること
  - reversed では stripe と counter endpoint の drawing 自体を変え、単純な color inversion にしていないこと
  - cap height / baseline / visual balance を使った alignment と scale relationships
  - photography/background 上の legibility と approved-master governance
- Useful for:
  - geometric equality と optical equality の違い
  - polarity-specific drawing
  - long-lived mark の governance
- Avoid copying:
  - IBM 固有の stripe construction、clear-space ratio、palette、legal rule

### Google Design — Evolving the Google Identity

- https://design.google/library/evolving-google-identity
- Observe:
  - full logotype、dynamic dots、small-context compact G を別 state として持つ system
  - compact G が logotype の単なる crop ではなく、小サイズで耐えるよう visual weight と join を optical refinement していること
  - size / weight の実 testing、screen/print usage spec、asset generation/version control
  - adjacent color が知覚的に暗くなることへの補正
- Useful for:
  - full ↔ compact distillation
  - small-size redrawing
  - mark variants を distribution system として運用する考え方
- Avoid copying:
  - Google 固有の color sequence、G geometry、grid、motion states

## Independent production identities — Pentagram

Pentagram だけを一般則の source にしない。以下は異なる mark decisions を比較する production evidence として使う。

### Yoto

- https://www.pentagram.com/work/yoto
- Observe:
  - physical product / print / digital と、極端に小さな pixel display を同じ identity が横断するための simplification
  - mark の意味・silhouette と display constraint の関係
- Useful for:
  - constrained-surface / low-resolution stress test
- Avoid copying:
  - Yoto の具体 symbol や、事例固有の pixel dimension を universal minimum にすること

### PayPal

- https://www.pentagram.com/work/paypal
- Observe:
  - existing monogram の recognition structure を大きく捨てず、corner / contrast / color relationship を更新する refresh
  - symbol と wordmark を固定 lockup から外し、独立運用可能にした理由
  - small-size utility typography と brand wordmark の役割差
- Useful for:
  - equity-preserving refresh
  - lockup independence
- Avoid copying:
  - monogram overlap、blue relationship、custom type construction

### Pyer Moss

- https://www.pentagram.com/work/pyer-moss
- Observe:
  - stacked / one-line 両方で wordmark を成立させるため、特定文字の幅と角度を optical / structural に調整していること
  - monogram と wordmark が異なる役割を持ちながら同じ identity family を作る方法
- Useful for:
  - wordmark variant / alignment problem
  - monogram relationship
- Avoid copying:
  - exact letter modifications、typeface、symbol metaphor

### The Hartford

- https://www.pentagram.com/work/the-hartford
- Observe:
  - established figurative mark の recognition を保ちながら、scale と digital/physical contexts で legibility を改善する simplification
- Useful for:
  - legacy/equity mark の detail reduction
- Avoid copying:
  - figurative silhouette や simplification level を別 brand にそのまま移すこと

## Independent production identities — Wolff Olins

### BMG

- https://wolffolins.com/work/bmg
- Observe:
  - existing wordmark の stability を残し、新しい symbol を追加して future expression を拡張した関係
  - symbol が pattern / icon system へ展開されても、mark と wider graphic grammar の役割を混同していないか
- Useful for:
  - existing equity + new symbol
  - mark-derived graphic system の境界
- Avoid copying:
  - BMG 固有の play/momentum metaphor や mark construction

### The Met

- https://wolffolins.com/work/the-met
- Observe:
  - lengthy formal name と lived/public name の関係が wordmark decision にどう影響するか
  - connected letterforms が recognition と tone を同時に担う方法
- Useful for:
  - naming reality と wordmark form の関係を観察する
- Avoid copying:
  - ligature-like construction や historical remix を generic cultural-logo recipe にすること

## Independent production identities — Studio Dumbar/DEPT®

### Tempo

- https://studiodumbar.com/work/tempo
- Observe:
  - primary wordmark に加えて standalone `T` を social avatar / favicon role に割り当てる明示的な compact-mark system
  - wordmark width behavior と compact mark の role を混同しないこと
- Useful for:
  - full mark と compact surface の責務分離
- Avoid copying:
  - `T` construction、variable-width expression、specific motion language

### Modyfi

- https://studiodumbar.com/work/modyfi
- Observe:
  - core `M` symbol の layers/angles が grids、shapes、numbers、icons 等へ recurrence する一方、symbol 自体の recognition anchor を維持すること
- Useful for:
  - mark geometry と wider identity grammar の接続
- Avoid copying:
  - Modyfi 固有の M shape、modifier effects、graphic language

### The Social Hub

- https://studiodumbar.com/work/the-social-hub
- Observe:
  - silhouette clarity を優先した hub symbol と、同じ symbol を playful illustration carrier に展開する違い
- Useful for:
  - core silhouette と expressive application の境界
- Avoid copying:
  - flower-like symbol や specific illustrative transformations

## Cross-reference questions

reference を開いたら次を比較する。

1. primary recognition は wordmark / symbol / monogram / relationship のどれか。
2. compact context は master の縮小で済ませているか、別 state / redrawing があるか。
3. geometric construction と optical correction が衝突した箇所はどこか。
4. positive / reversed / monochrome で drawing 自体が変わるか。
5. symbol と wordmark は固定 lockup か、context で独立できるか。
6. silhouette と internal detail のどちらが small-size recognition を担うか。
7. crop / background / neighboring marks で optical center / prominence がどう変わるか。
8. mark 由来の pattern / icon / motion と、mark 自体の canonical geometry をどう区別しているか。
9. existing equity を残す refresh と、new mark creation では何が違うか。
10. approved master / trademark / asset distribution が uncontrolled modification をどう防いでいるか。
