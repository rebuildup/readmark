## Observation matrix

各 reference を最低限次で比較する。

| Axis | Questions |
| --- | --- |
| Lyric source | official/approved text は何か、ad-lib/backing を含むか |
| Timing unit | phrase / line / word / syllable のどれが主か |
| Reading timing | vocal より前 / 同時 / 後の exposure はどう設計されるか |
| Section grammar | verse / chorus / bridge / instrumental がどう区別されるか |
| Repetition | chorus 再登場で何を保持し何を変えるか |
| No-vocal state | instrumental / rest で text と image はどう振る舞うか |
| Voice ownership | duet / group / backing / ad-lib をどう区別するか |
| Type-image relationship | type-led / image-led / embedded / overlay / mixed |
| Semantic relationship | lyric meaning / song arc / beat / mood のどれに response しているか |
| Full-song hierarchy | climax / final chorus / outro まで progression があるか |
| Delivery | viewing size / aspect / compression で lyric が生き残るか |

## Translation rules

複数 reference に共通して見える構造を current artifact へ翻訳する。

- exact visual style ではなく section / timing / hierarchy relationship を抽出する
- phrase timing と lexical readability を優先し、word-level animation は目的がある箇所へ限定する
- chorus recurrence では recognition anchor と progression variation の両方を見る
- lyric がない時間を visual-only state として認める
- image-led reference から「lyrics を小さくしてよい」という結論を出さず、実 delivered size で読めるか確認する
- performer / IP / brand asset は project 固有物として扱い、universal design rule にしない

## Failure modes to compare against

- transcription error / wrong lyric version
- phrase association が vocal とずれる
- exact word sync が細かすぎて whole phrase を読めない
- every-word motion により emphasis contrast が消える
- chorus copy-paste が full-song progression を止める
- chorus を毎回別 visual にして refrain identity が消える
- instrumental gap で stale text が残る
- simultaneous voices が重なり読めない
- singer identity を color-only にする
- visual metaphor が lyric を隠す
- section transition が曲構造と無関係
- vertical crop で line break / lyric order / focal image が破綻する

## Verification target

実 project trial では最低限次を含む track を選ぶか、fixture を用意する。

- repeated chorus/refrain
- at least one no-vocal / instrumental interval
- one dense or fast lyric passage
- one sustained lyric
- section transition
- possible backing/ad-lib or multiple voice if domain requires it

Final artifact では:

1. approved lyric source と全編照合
2. normal-speed complete-track playback
3. fast/dense/repeated/no-vocal/overlap sections の scrub inspection
4. target viewing size で readability inspection
5. required aspect-ratio exports の playback
6. final encoded file の typography edge / contrast / compression check

を行う。
