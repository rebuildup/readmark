# Music Promo Video References

Last reviewed: 2026-09-14

この reference set は music release campaign の video / motion asset を設計するときに使う。

単一 creator の visual style を再現するためではなく、**campaign phase、audio excerpt、reveal budget、asset family、platform role、medium translation**を比較する。

## Current platform / first-party guidance

### YouTube for Artists — Artist Resources

- https://artists.youtube.com/
- Observe:
  - Pre-Release Strategy / Release Day Strategy / Post-Release Strategy を別の campaign phase として扱う構造
  - music release を multi-format plan として扱うこと
  - Official Artist Channel / Shorts / music video 等、surface ごとに役割が異なること
- Useful for:
  - campaign phase を一つの「公開動画」に潰さない
  - platform format を release lifecycle へ配置する
- Avoid copying:
  - current YouTube format や distribution feature を universal duration / composition rule にすること

### Spotify for Artists — Video & Visuals

- https://artists.spotify.com/video-and-visuals
- Observe:
  - full music video、Canvas、Countdown Page / pre-release visual が異なる listening / discovery role を持つこと
  - visual が artist profile / release / Now Playing 等の context に置かれること
  - artist world を music と一緒に継続する考え方
- Useful for:
  - streaming platform 内で asset の job と surrounding metadata を確認する
- Avoid copying:
  - Spotify 固有 UI を他 platform の design system として扱うこと

### Spotify for Artists — Canvas

- https://artists.spotify.com/canvas
- Observe:
  - Canvas が Now Playing 内で track に結び付く short looping visual であること
  - cover artwork と同じ file ではなく、listening 中の visual layer として機能すること
  - 2D / 3D / mixed media / footage 等、visual source は一種類に限定されていないこと
- Useful for:
  - now-playing loop の platform role を理解する
- Avoid copying:
  - Canvas 固有 duration や UI behavior を全 music promo の universal rule にすること

### Spotify for Artists — Preparing for Release Day and Beyond

- https://artists.spotify.com/blog/release-guide-preparing-for-release-day
- Observe:
  - release 前後で music video / Canvas 等の visual asset を準備・展開する考え方
  - Canvas が track ごとの short loop として release に組み込まれること
  - release-day だけで campaign を終えず、その後も fan connection を継続すること
- Useful for:
  - asset を release lifecycle に置く
  - visual delivery を audio release と同期する
- Avoid copying:
  - engagement metric を visual quality の直接尺度にすること

### Spotify for Artists — New Releases

- https://artists.spotify.com/new-releases
- Observe:
  - Countdown Pages、music video、Canvas が release preparation の別 surface として併存すること
  - pre-release tease と first-stream experience の違い
- Useful for:
  - teaser / pre-save / now-playing asset を同一目的にしない

### Spotify for Artists — Countdown Pages

- https://artists.spotify.com/countdown-pages
- Observe:
  - pre-save、tracklist preview、countdown videos 等が upcoming release の context にまとめられていること
  - release 前の video が「まだ聴けない状態」で何を伝えるか
- Useful for:
  - pre-release phase の information / reveal state を設計する

## Production / campaign artifacts

### Studio Moross — Jade Bird, Burn The Hard Drive

- https://www.studiomoross.com/work/burn-the-hard-drive
- Year: 2024
- Observe:
  - EP の song themes から campaign concept を抽出していること
  - music video では candid footage + deletion/distortion language、print では die-cut / etched type と、同じ concept を medium-specific に翻訳していること
  - campaign / artwork / music video / photography / packaging が一つの visual world を共有しつつ identical execution ではないこと
- Useful for:
  - coherence と literal repetition を分ける
  - visual concept を motion / print / packaging へ適応する
- Avoid copying:
  - data-mosh / blur / erased-figure effect 自体を music campaign の rule にすること

### Studio Moross — Darude, Storm 25

- https://www.studiomoross.com/work/darude-storm-25
- Year: 2025
- Observe:
  - teaser video と announcement video が別 asset として存在すること
  - archive footage / iconic sunglasses / nostalgia を recognition anchor にしていること
  - anniversary / catalog moment では new-release secrecy と異なる audience knowledge を利用できること
- Useful for:
  - teaser / announcement の役割差
  - audience prior knowledge と archive source の関係
- Avoid copying:
  - nostalgia / archive treatment を new release に無条件適用すること

### BABYDADDY — EP Launch Campaign

- https://www.behance.net/gallery/244005571/BABYDADDY-EP-Launch-Campaign
- Published: 2026-02-12
- Observe:
  - release 前から interest を作るため visual language を段階的に導入していること
  - single artwork、EP cover、Spotify Canvases、photography、merch、music video を同一 rollout で扱うこと
  - cohesion を保ちながら repetition を避けていること
  - music video は wider campaign と tone / texture でつながり、literal repetition ではないこと
- Useful for:
  - asset-family continuity
  - gradual reveal / rollout
  - independent release での flexible cross-format system
- Avoid copying:
  - rough / lo-fi aesthetic を release campaign の一般原則にすること

### Crazy — Conceptual Visualizer and Stories

- https://www.behance.net/gallery/243680061/Crazy-Conceptual-Visualizer-and-Stories
- Published: 2026-02-06
- Observe:
  - visualizer と複数 short-form story pieces を一つの teaser campaign として構成していること
  - release 前に project aesthetic を伝えつつ final outcome を全部 reveal しない設計
  - rhythm / contrast / texture を song と関連付けつつ、asset role を分けていること
- Useful for:
  - reveal budget
  - one release から複数 short-form role を作る
- Avoid copying:
  - specific texture / storyboard / creator expression を style preset 化すること

## Comparison questions

reference を開いたら最低限次を比較する。

1. この asset は pre-release / announcement / release-day / post-release / now-playing のどの job か
2. viewer が既に知っている artist / song / artwork / motif は何か
3. audio excerpt はどの section を使い、recognition / mood / surprise / lyric のどれを優先しているか
4.何を reveal し、何を later asset に残しているか
5. artist / artwork / archive / narrative / graphic / visualizer のどれが visual source か
6. asset family のどの identity cue を保持し、どの部分を medium / platform ごとに変えているか
7. platform が既に提供する title / artist / cover / CTA と video 内情報が重複していないか
8. sound-on と silent-preview で campaign identity がどう変わるか
9. loop / replay / short-form viewing で fatigue や reset が発生しないか
10. campaign message が公開時点の release state と一致しているか

## Translation reminder

- exact duration、crop、text amount、platform UI は current task 時点の official guidance を再確認する。
- creator 固有の effect、artist asset、campaign copy、exact color / type を再利用しない。
- reference から持ち帰るのは campaign phase、identity continuity、audio/reveal relationship、medium adaptation、verification の判断軸である。
