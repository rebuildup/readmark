# Poster Design References

Last reviewed: 2026-09-14

この reference family は poster の「見た目」をコピーするためではなく、**遭遇条件・first/second read・視線誘導・情報密度・series variation・媒体 translation** を比較するために使う。

1作品・1時代・1studio から poster 全般の style rule を一般化しない。

## Established analysis / canonical collections

### Cooper Hewitt — How Posters Work

- URL: https://www.cooperhewitt.org/exhibitions/how-posters-work/
- Type: museum exhibition / established analysis
- Observe:
  - poster を perception / storytelling / 2D visual communication の問題として扱っている点
  - central image、text-as-image、overlap、scale、diagonal、system 等の異なる visual mechanisms
  - 同じ「poster」という媒体でも mechanism が一つに収束しないこと
- Useful for:
  - communication mechanism の候補を広げる
  - vague style adjective を observable relation へ分解する
- Avoid copying:
  - exhibition 内の個別 designer の proprietary expression
  - technique list を checklist のように全部同時使用すること

### Cooper Hewitt — Posters with a Central Image

- URL: https://www.cooperhewitt.org/2015/05/28/posters-with-a-central-image/
- Type: museum analysis / composition case
- Observe:
  - central-image formula が easy/effective solution にも、creative departure にもなり得る点
  - Felix Pfäffli の `Future Islands` poster で central void が focus と surface behavior を作る点
- Useful for:
  - 「中央に大きい image」が poster の universal grammar ではないと判断する
  - focal device と cliché の境界を考える
- Avoid copying:
  - circle / central void 自体を poster recipe にすること

### Cooper Hewitt — Making a Poster is a Process

- URL: https://www.cooperhewitt.org/2014/12/05/making-a-poster-is-a-process/
- Type: museum / designer process evidence
- Observe:
  - title / letterform が information と graphic focus の双方へ変化する過程
  - finished style ではなく iteration によって relationship を探る点
- Useful for:
  - type-led poster の検討
  - communication mechanism が不明な場合の materially different study
- Avoid copying:
  - one designer's letterform treatment

### Cooper Hewitt — Jazz Typography

- URL: https://www.cooperhewitt.org/2015/05/27/jazz-typography/
- Type: museum / poster-series analysis
- Observe:
  - Niklaus Troxler の poster series で typography が各演目へ異なる反応をしながら、継続的な authorial/system identity を持つ点
  - rhythm / image / lettering の関係
- Useful for:
  - poster series の variation
  - type を literal information 以上の role で使う場合
- Avoid copying:
  - jazz という content と特定 lettering style を固定対応させること

### MoMA — Typography and the Poster

- URL: https://www.moma.org/calendar/exhibitions/443
- Type: museum exhibition / historical breadth
- Observe:
  - typography が passive support から expressive medium まで広い役割を持つ poster history
  -時代・目的ごとに text/image hierarchy が変わる点
- Useful for:
  - type-led / image-led / hybrid を一つの正解へ収束させないための historical comparison
- Avoid copying:
  - historical surface treatment を current artifact の style filter にすること

### MoMA — Paula Scher, The Public Theater, 95-96 Season

- URL: https://www.moma.org/collection/works/8840
- Type: canonical production artifact
- Observe:
  - text-heavy poster が大量情報を size / weight / color / spacing の差で dynamic hierarchy にする方法
  - neat grid を外れても information routing が失われない条件
  - institution positioning と typography emphasis の関係
- Useful for:
  - high-density poster
  - copy 削減が困難な event / season poster
- Avoid copying:
  - Paula Scher 固有の font mixture、spacing、historic-type treatment
  - `dense = expressive` という短絡

## Localization / adaptation

### Poster House — The Push Pin Style (Tokyo variant)

- URL: https://collection.posterhouse.org/poster/the-push-pin-style/
- Type: museum collection / localized variant
- Observe:
  - travelling exhibition の各 venue で variant を作ったこと
  - Tokyo 版で palette / lower composition / English + Japanese information が変化していること
  - motif を保持しつつ local information を artifact の一部として再構成する方法
- Useful for:
  - multilingual / venue adaptation
  - family continuity vs local variation
- Avoid copying:
  - Push Pin motif、palette、period style

### Poster House — The Swiss Grid

- URL: https://posterhouse.org/exhibition/the-swiss-grid/
- Type: museum exhibition / historical system evidence
- Observe:
  - geometric grid が clarity / organization / repeatability を支える例
  - grid が特定歴史的 practice であり poster 全般の唯一の grammar ではない点
- Useful for:
  - systematic alignment を必要とする poster
  - grid と controlled break の比較
- Avoid copying:
  - Swiss grid を universal default にすること
  - exact column count / margin / type scale の転用

## Production poster systems

### Studio Dumbar — Amsterdam Sinfonietta

- URL: https://studiodumbar.com/work/amsterdam-sinfonietta
- Type: long-running production poster series
- Observe:
  - seasonal poster series が毎回大きく変化しながら organization として recognizable である点
  - individual poster が performance の musical theme に応答する点
  - series identity を fixed template ではなく retained qualities / recurring signature と variation で成立させる方法
- Useful for:
  - concert / cultural poster series
  - retained vs changed property の設計
- Avoid copying:
  - individual series の image-making technique
  - `different designer every season` を一般運用 rule にすること

### Studio Dumbar — Pulchri Studio

- URL: https://studiodumbar.com/work/pulchri-studio
- Type: production poster campaigns
- Observe:
  - year-to-year visual change と organization-level continuity の両立
  - print poster / flyer / brochure へ展開するときの shared identity と artifact-specific composition
  - bright color / type / abstract image 等が style token ではなく broader strategy の中で使われる点
- Useful for:
  - cultural organization の recurring poster program
  - poster と近接 artifact の境界比較
- Avoid copying:
  - described palette/type/image traits を Pulchri 外へ style formula として移植すること

### Pentagram — London Design Biennale 2025

- URL: https://www.pentagram.com/work/london-design-biennale-2025
- Type: recent production campaign / 2025
- Observe:
  - campaign identity が posters、signage、print、online へ展開される際の adaptation
  - one graphic mark が 2D / 3D application で役割を変える点
  - poster を campaign identity そのものではなく application surface の一つとして見ること
- Useful for:
  - `key-visual-design` との責務境界
  - campaign master concept から poster へ適応するケース
- Avoid copying:
  - Biennale 固有の mark / palette / 2D-3D expression

## Selection guidance

### Exhibition / cultural event poster

最低限比較する:

- `How Posters Work`
- MoMA Public Theater または Typography and the Poster
- Amsterdam Sinfonietta / Pulchri / London Design Biennale のうち task に近い production case

### Text-dense poster

優先する:

- MoMA Public Theater
- `How Posters Work`
-必要なら grid 系 reference と比較し、density を one style に固定しない

### Poster series

優先する:

- Amsterdam Sinfonietta
- Pulchri Studio
- Push Pin Tokyo variant

比較する軸:

- retained property
- changed property
- content-specific reason
- family recognition
- individual differentiation

### Localized / travelling poster

優先する:

- Push Pin Tokyo variant
- task の current locale / venue requirements

translated text の追加を最後の fit 問題として扱わない。

### Campaign-derived poster

優先する:

- London Design Biennale 2025
- task の actual brand/key-visual source
- poster-specific encounter references

master identity の crop だけで済ませず、poster format / distance / logistics に再翻訳する。

## Runtime research rules

- current platform / venue / campaign の仕様が重要なら、実行時に official source を再確認する
- poster の歴史的 surface を current trend と誤認しない
- style / culture を扱う場合は複数 creator / multiple works を追加調査する
- reference 画像を閲覧できない場合、text summary だけで exact visual rule を発明しない
- exact sizes、margins、type scales、paper stocks は reference-specific evidence として扱い、current artifact の constraints から再決定する
- rights / licensing が必要な画像・作品は、観察 reference と production asset permission を分離する
