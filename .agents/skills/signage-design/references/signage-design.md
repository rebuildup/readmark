# Signage Design References

Last reviewed: 2026-09-15

この reference set は、signage / wayfinding を一つの visual style として学ぶためではなく、**journey、decision point、information role、accessibility、environment、maintenance、installed verification** を比較するために使う。

current regulation / public guidance は project 開始時に status と jurisdiction を再確認する。

## How to compare references

最低限、次を横断して比較する。

- 誰がどの journey を移動するか
- sign の role: identification / orientation / direction / confirmation / information / regulation / safety
- decision point と placement / sightline
- destination naming / numbering / route hierarchy
- viewing distance / approach / speed / lighting / clutter
- typography / symbol / color が担う機能
- visual / tactile / multilingual information
- architecture / landmark / map / staff と sign の責務分担
- sign family の retained cue と role-specific variation
- update / maintenance / physical durability
- prototype / user test / installed-system evaluation

一つの source の寸法、palette、typeface、material、arrow style を別 project の default にしない。

## Primary / official guidance

### U.S. Access Board — ADA Guide, Chapter 7: Signs

- URL: https://www.access-board.gov/ada/guides/chapter-7-signs/
- Type: official accessibility guidance / U.S. ADA Standards explanation
- Observe:
  - sign content role によって visual-only / tactile+visual requirement が異なること
  - permanent room identification、directional / informational、accessibility symbols、egress-related content の区別
  - visual character の viewing distance / mounting / finish / contrast と、tactile character / braille の別 requirement
  - tactile sign の location を、利用者が touch で見つける environmental cue として扱っていること
- Useful for:
  - applicable U.S. project の compliance scope を切り分ける
  - 「sign 全体に一つの accessibility rule」を当てない判断
  - visual information と tactile information の役割分離
- Avoid copying:
  - ADA の numeric values を米国外または別 sign category の universal design rule にしない
  - ADA compliance だけを complete wayfinding design と扱わない

### Transport for London — Legible London: Maps & signs

- URL: https://tfl.gov.uk/info-for/boroughs-and-communities/maps-and-signs
- Type: current first-party public wayfinding system
- Observe:
  - streetscape と information need に応じた monolith / minilith / interlith / fingerpost / wall-mounted / digital sign の使い分け
  - heads-up mapping により user orientation と map orientation を合わせる判断
  - map 内の walking-time、landmark illustration、integrated transport、street finder の information layers
  - accessibility を sign height / mobility information / high contrast と環境上の使い方へ接続していること
  - map data と physical sign を継続的に maintain/update する ownership
  - wayfinding map を advertising inventory と混同しない content governance
- Useful for:
  - public-realm route / map / sign family
  - physical constraints に応じて form factor を変えつつ一つの system を維持する例
  - environmental information と maintenance を一体で見る
- Avoid copying:
  - navy/yellow、product dimensions、London-specific map grammar を generic city-wayfinding style にしない

### NHS England — Wayfinding: effective wayfinding and signing systems guidance for healthcare facilities

- URL: https://www.england.nhs.uk/publication/wayfinding-effective-wayfinding-and-signing-systems-guidance-for-healthcare-facilities/
- Type: official healthcare-estates guidance
- Status note:
  - NHS England page first published 2021-05-21, updated 2021-08-31
  - hosted guidance document itself is the 2005 edition; use as established healthcare guidance and re-check current local requirements before implementation
- Observe:
  - healthcare site を arrival 前情報から building identification、entrance、internal route、destination まで一つの journey として扱う考え方
  - anxiety / unfamiliarity / complex campus conditions が information intake と navigation に与える影響
  - locational / directional signs を approach direction と building context に置く考え方
  - architecture、landmarks、naming、staff guidance と signs の関係
- Useful for:
  - hospitals / clinics / complex campuses
  - high-stress first-time journeys
  - sign placement を flat artwork ではなく route experience として考える
- Avoid copying:
  - 2005 document の numeric recommendations を current code とみなさない
  - healthcare-specific assumptions を airport / city / office へ無条件に転用しない

### Government Property Agency — Workplace Design Guide: Design approach

- URL: https://144.gpa.gov.uk/workplace-design-guide-design-approach/
- Type: official UK government workplace guidance
- Observe:
  - wayfinding / signage を lighting、finishes、layout、artwork、identity と coordinated な layer として扱うこと
  - clear naming / numbering / visual cues で large / complex building の journey を支えること
  - artwork や environmental features も zone differentiation / wayfinding を補助できること
  - unnecessary visual clutter を増やさず confidence を支える考え方
- Useful for:
  - workplace / office / public building の integrated environment
  - brand integration と functional wayfinding の責務分担
- Avoid copying:
  - government workplace の identity hierarchy を他 organization へそのまま適用しない

### Japan MLIT — Public transport accessibility guidelines

- URL: https://www.mlit.go.jp/sogoseisaku/barrierfree/sosei_barrierfree_mn_000001.html
- Type: current official Japanese public-transport accessibility guidance hub
- Current-status evidence:
  - 2025-09-30 に国土交通省が移動等円滑化整備ガイドラインの改訂を公表
  - current hub は旅客施設編の「誘導案内設備に関するガイドライン」を含む
- Observe:
  - public transport における movement route と guidance equipment の relationship
  - 高齢者・障害者等を含む diverse users の needs と施設条件を踏まえた整備判断
  - mandatory standard と guideline / recommended level の区別
  - facility-specific constraints を踏まえながら rationale を理解して設計水準を判断する考え方
- Useful for:
  - Japan の駅 / terminal / public-transport projects
  - applicable guidance の current version を辿る入口
- Avoid copying:
  - transport-specific requirement を一般 office / museum / retail の universal specification にしない

### Japan MLIT — Public information symbols / JIS Z8210 guidance

- URL: https://www.mlit.go.jp/sogoseisaku/barrierfree/sosei_barrierfree_tk_000145.html
- Type: official public-information symbol guidance
- Observe:
  - 旅客施設での誘導 / 位置 / 案内 sign に standardized pictogram family を使う考え方
  - JIS Z8210 と補助的な標準案内用図記号の relationship
- Useful for:
  - Japan の public / transport environments で custom icon を作る前の standard-symbol check
- Avoid copying:
  - standardized symbol の geometry を独自 style へ無根拠に改変しない
  - symbol が存在することだけで placement / naming / route logic が解決したと考えない

### Japan Tourism Agency — Foreign-language information in public transport

- URL: https://www.mlit.go.jp/kankocho/shisaku/kankochi/koukyou.html
- Type: official multilingual public-transport guidance
- Observe:
  - direction / position / usage / regulation informationを text・pictogram・audio で提供する modality split
  - Japanese + English + pictogram を基本とし、regional need に応じて Chinese / Korean 等を加える policy context
  - station / map / fare / destination 等、journey 上の複数 touchpoint に multilingual information を連続させること
- Useful for:
  - Japan の transport / visitor environments
  - language count ではなく journey-wide information continuity を考える
- Avoid copying:
  - この language policy を private / non-transport environment の universal language order とみなさない

## Independent production systems

### Applied Information Group — Leer Madrid

- URL: https://appliedinformation.group/projects/leer-madrid
- Type: current city wayfinding production + prototype evaluation
- Observe:
  - resident / visitor research から cohesive on-street map/sign system へ変換した過程
  - nomenclature の rationalisation を graphic styling より前の system problem として扱うこと
  - accessibility を age / language / physical / cognitive ability を横断する system goal にしていること
  - prototype installation 後に observation と interviews を行い、city-wide rollout 前に評価していること
  - typography に city character と practical hierarchy の両方の role を持たせるが、一つの type style に system を依存させないこと
- Useful for:
  - city/public-realm wayfinding
  - naming → prototype → user evaluation の end-to-end evidence
- Avoid copying:
  - Madrid 固有の typeface / identity expression を generic wayfinding aesthetic にしない

### DNCO — V&A Wayfinding

- URL: https://dnco.com/work/the-va-wayfinding
- Type: museum wayfinding production system
- Observe:
  - threshold に confirmation signs を置き、長い route を trail of breadcrumbs として reassurance すること
  - floor numbering 自体を reconsider して navigation difficulty を減らすこと
  - paid exhibition color を selective beacon として使い、全情報を color coding しないこと
  - printed/digital map の vertical circulation alignment と icon scale
  - museum objects と競合しない material / prominence の調整
  - signs と gallery assistants を complementary touchpoints として扱うこと
- Useful for:
  - museum / cultural venue / complex building
  - route reassurance、renaming/renumbering、content priority、material discretion
- Avoid copying:
  - black timber、exhibition color treatment、floor renumberingを形式として模倣しない

### Maynard Design — Auckland Airport

- URL: https://www.maynard-design.com/project/auckland-airport/
- Type: airport / multilingual transport wayfinding production
- Observe:
  - existing + future terminal environments を跨ぐ scalable sign system
  - te reo Māori / English / simplified Chinese の trilingual integration
  - large spatial scale と expanding terminal complexity を system requirement にしていること
  - local place character と high-functionality / legibility を共存させる判断
  - multiple architectural settings へ sign family を適応する versatility
- Useful for:
  - airports / transport hubs / multilingual high-consequence journeys
  - growth / phased implementation / language integration
- Avoid copying:
  - language order、material、local motif、airport-specific hierarchy を他 context の default にしない

### Maynard Design — Surrey Legible City

- URL: https://www.maynard-design.com/project/surrey-legible-city/
- Type: city wayfinding / product-family / prototype production
- Observe:
  - three towns で common system と location-specific expression を分ける retained-vs-variable logic
  - sign product family、mapping style、graphic layout、placement strategy を一体で設計すること
  - full-scale mock-ups / prototyping / material trials で form と function を refinement すること
  - implementation plan を sign artwork と別に持つこと
- Useful for:
  - multi-site sign family
  - common system + local variation
  - full-scale physical prototyping
- Avoid copying:
  - county-specific palette / materials / pictogram family を universal solution にしない

## Comparison notes

### Signage is not only a graphic layer

Official guidance と production examples に共通するのは、signage が **place + information + route + installation** の system であること。

- TfL は streetscape constraint と information need で sign form を変える。
- V&A は floor numbering と threshold confirmation を redesign する。
- Leer Madrid は nomenclature を整理してから signs/maps を一つの system にする。
- NHS は healthcare journey と building identification を含む broader wayfinding problem として扱う。

したがって、sign panel の graphic composition だけを最適化しても route system は完成しない。

### Accessibility requirements are role- and jurisdiction-dependent

- ADA では permanent room designation、directional/informational、accessibility symbol 等で applicable requirement が異なる。
- Japan の MLIT guidance は public transport の facility / guidance equipment context を持つ。
- multilingual policy も public-transport / visitor context に依存する。

よって「sign は常にこの文字サイズ / mounting height / language order」という cross-project magic number を作らない。

### Recognition and local character can coexist, but function wins

- Auckland Airport は local identity と trilingual legibility を共存させる。
- V&A は exhibition color を selective beacon として使う。
- Surrey は common system と town-specific material variation を分離する。
- GPA は branding / artwork を wayfinding と coordinate する。

brand / place expression は route information の recognition を助ける範囲で使い、safety / accessibility / destination clarity と競合させない。

### Prototype the route, not only the panel

- Leer Madrid は installed prototypes を observation / interview で評価している。
- Surrey は full-scale mock-ups と material trials を行っている。
- TfL の system は environment constraints に合わせて複数 product types を持つ。

したがって final verification は Figma/Illustrator artboard や photomontage で終了せず、actual-size / sightline / decision point / route continuity を検証する。

## Research gaps / project-specific checks

実案件では reference research を次まで追加する。

- applicable national / local building, fire, traffic, transport, accessibility code
- owner/operator signage standards
- current architecture / site plan / destination list
- actual language audiences and translation governance
- emergency / temporary operation plans
- fabrication / mounting / lighting / maintenance constraints
- relevant user research, including disabled users where applicable

この file は legal / code advice の代替ではない。governing standard の current text を project ごとに確認する。
