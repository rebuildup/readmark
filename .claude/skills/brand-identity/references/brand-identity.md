# Brand Identity References

Last reviewed: 2026-09-15

この reference set は style gallery ではない。brand identity が長期的な recognition をどのような **関係 / rule / application system** で保つかを比較するために使う。

一つの source の visual expression を clone しない。current brand truth、audience、existing equity、architecture、delivery contexts に翻訳する。

## Current public brand systems

### GitHub Brand Toolkit

- https://brand.github.com/
- https://brand.github.com/brand-identity
- https://brand.github.com/foundations/color
- https://brand.github.com/foundations/typography
- https://brand.github.com/graphic-elements/illustration
- https://brand.github.com/motion/principles

Observe:

- identity が brand attributes、logo、type、color、illustration、layout、product relationship、motion、applications へ分かれている構造
- context により brand attribute の一部が前へ出る一方、core identity から分離させない考え方
- core brand と Copilot / Security の scoped expression relationship
- primary recognition color と secondary expression の役割分担
- typography の relationship は保ちながら environment ごとの point size / line-height を固定しない考え方
- illustration loudness を content/occasion に応じて変える system
- static foundations と motion identity が別々の asset collectionではなく同一 brand systemとして接続される点

Useful for:

- mature product brand の core / product-family relationship
- restrained ↔ expressive range
- brand system と product/marketing systems の境界

Avoid copying:

- GitHub Green、Mona Sans、Octocat、contribution graph、exact palette percentage、layout/illustration assets

Current note:

- Brand Toolkit は 2026 content として公開され、brand identity / foundations / graphic elements / brand in action / motion identity を current structure として持つ。

### IBM Design Language

- https://www.ibm.com/design/language/
- https://www.ibm.com/design/language/philosophy/pov/

Observe:

- philosophy から typography / color / grid / logos / iconography / illustration / photography / data visualization / layout / animation までを一つの recognizable system として接続する方法
- identity element を各 discipline の exact asset だけでなく、repeated design relationships として扱う方法
- marketing / product / event / workplace 等の実装領域を core language から派生させる構造
- long-lived system が tools / templates / resources を通して team scale する方法

Useful for:

- 多数の product / media / teams を持つ durable identity
- foundation と application の階層化
- governance / reusable design language

Avoid copying:

- IBM Plex、8-Bar、2x Grid、IBM blue、Rebus、specific illustration or photography treatment

Current note:

- Home page reports `Last updated 10 September 2026` at review time.

### Wikimedia Foundation — Brand stewardship / creation and protection

- https://wikimediafoundation.org/brand-stewardship/
- https://wikimediafoundation.org/brand-stewardship/brand-creation-and-protection/

Observe:

- logo/color/name だけでなく、recognition / meaning / equity と trademark asset を区別する考え方
- distinctiveness、source identification、global/universal applicability を brand asset creation の制約として扱う点
- community / global context で cultural/language dependence をどう問題化するか

Useful for:

- rights / trademark / source ownership を持つ identity
- global / multilingual system
- brand asset と broader brand equity の区別

Avoid copying:

- Wikimedia marks、movement-specific governance process、legal conclusions

## Independent production systems

### Wolff Olins — Patreon

- https://wolffolins.com/work/patreon

Observe:

- creator individualityを受け止めるために identity 自体を living / customizable system として設計する方法
- central brand recognition と creator-owned variation の共存
- mark / type / 3D / motion / customizable surfaces の relationship
- system の長期 co-creation を前提にした flexibility

Useful for:

- platform / community brand
- user-generated variation を許容する identity
- flexibility が core recognition を壊しやすい問題

Avoid copying:

- Patreon mark、custom type、3D treatment、creator-specific visual assets

### Wolff Olins — Decathlon

- https://wolffolins.com/work/decathlon

Observe:

- 多数の既存 sub-brands を unified parent identity へ整理する architecture change
- mark、type、art direction、motion、iconography を一つの global sports brand systemへ接続する方法
- legacy recognition と future portfolio simplification の trade-off

Useful for:

- parent/sub-brand consolidation
- global organization / product portfolio
- identity refresh で existing equity を扱う場合

Avoid copying:

- Decathlon symbol、typeface、sports-specific motion/art direction

### Wolff Olins — New York Botanical Garden

- https://www.wolffolins.com/work/nybg

Observe:

- organization purpose / role を core idea にして logo、voice、color、applications へ翻訳する方法
- year-round variety を許しながら institution recognition を保つ expression range
- onsite / digital / audience variation を受け止める operational usability

Useful for:

- cultural / institutional identity
- seasonal content が多い durable brand
- expressive variation と institutional trust の両立

Avoid copying:

- custom letterforms、specific palette、nature-derived visual motifs

### Studio Dumbar — Wabi

- https://studiodumbar.com/work/wabi

Observe:

- positioning (`Your OS, Your World, Your Way`) と personal/customizable product promise を identity behavior へ翻訳する方法
- visual identity / motion / sound が同じ brand premise を担う関係
- highly variable user-facing product と central identity の balance

Useful for:

- digital-first product brand
- personalization / customization が product truth に含まれる場合
- static asset だけでは identity を説明できない場合

Avoid copying:

- Wabi-specific marks、motion、sound、visual treatment

### Studio Dumbar — Modyfi

- https://studiodumbar.com/work/modyfi

Observe:

- positioning (`Made to Move`) を core symbol、grid/layout、shape、number、icon、effect、sound へ再帰的に展開する方法
-一つの recognizable idea が複数 discipline の relation rule になる仕組み
- dynamic identity が arbitrary effect collection へ崩れないための recurring geometry / behavior

Useful for:

- motion-native / creative-tool identity
- one proposition を cross-disciplinary grammar にする場合
- static ↔ motion continuity

Avoid copying:

- evolving M、angles/layers、specific effects、palette、sound logo

### Pentagram — Scenario

- https://www.pentagram.com/work/scenario

Observe:

- wordmark / modular grid が print / digital / photography framing へ展開される relationship
- Chinese / Latin typography を同一 identity 内で役割分担する方法
- commissioned photography と graphic system の接続

Useful for:

- multilingual identity
- relatively small number of strong structural cues から多媒体へ展開する場合
- type + image system

Avoid copying:

- 3×3 grid、custom wordmark、中国語字形、color blocks、photography

### Pentagram — R² Factory

- https://www.pentagram.com/work/r2-factory

Observe:

- parent organization から distinct でありつつ credibility / family relation を保つ identity
- logo、color、portrait photography、iconography の役割分担
- enterprise / regulated context と creative problem-solving personality の両立

Useful for:

- endorsed / parent-child brand relationship
- B2B / enterprise brand が独自 expression を必要とする場合
- architecture と visual distinctiveness の trade-off

Avoid copying:

- R² wordmark、palette、square portraits、icon set

## Comparison prompts

reference を開いた後、最低限比較する。

```text
What is durable?
What is allowed to change?
What actually carries recognition besides the logo?
How does expression become louder or quieter?
How are parent/product/campaign relationships shown?
What happens in a dense utility surface?
What happens in small / monochrome / multilingual use?
Could a designer outside the original team generate a coherent new application from the rules?
```

一つの reference で答えを固定しない。少なくとも current public system と materially different production identity を組み合わせて current project へ翻訳する。
