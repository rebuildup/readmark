# Event Flyer References

Last reviewed: 2026-09-14

flyer を一つの scene/style から一般化しない。historical ephemera、museum archive、event identity production を比較し、**distribution / close reading / logistics / handling / next-step** の違いを見る。

## Museum / archive evidence

- [Cooper Hewitt — Art of Noise in-gallery resources](https://www.cooperhewitt.org/art-of-noise-resources/)
  - Observe: posters と flyers/handbills が同じ music-event culture の中でも別の graphic artifacts として蓄積されていること、genre と production process の関係。
  - Useful for: flyer を poster の単なる縮小版とみなさず、event announcement ephemera として位置付ける。
  - Avoid copying: punk の photocopy roughness、psychedelic color、genre 固有表現を universal flyer style にしない。

- [MoMA — Please Come to the Show, Part 2](https://www.moma.org/interactives/exhibitions/2013/please_come_show_part2/)
  - Observe: invitation cards、small posters、flyers が conceptual works、performances、screenings への「invitation」自体を構成していること。
  - Useful for: flyer の役割を advertising image だけでなく event への threshold / invitation として考える。
  - Avoid copying: artist-specific ephemera の conceptual gesture を一般的 event flyer の必須要素にしない。

- [MoMA Archives — Department of Graphics Records](https://www.moma.org/research/archives/finding-aids/Graphicsb.html)
  - Observe: exhibitions、film screenings、lectures、concerts 等に対し invitations、brochures、tickets、flyers、posters が用途別に併存していたこと。同一 event でも複数 version/colorway が存在すること。
  - Useful for: artifact role、event series、variant、collateral relationship の境界を考える。
  - Avoid copying: museum institutional hierarchy をあらゆる event にそのまま適用しない。

- [Walker Art Center — Promotional flyer for Yoko Ono's 13 Days Do-it-Yourself Dance Festival](https://www.walkerart.org/collections/artwork/promotional-flyer-for-yoko-ono-s-13-days-do-it-yourself-dance-festival-london/)
  - Observe: 1967年の 10×8 inch offset-lithograph flyer という物理的 scale / medium / event-specific ephemera の事実。
  - Useful for: flyer が portable single-sheet artifact として成立してきた historical evidence。
  - Avoid copying: historical dimensions や offset process を current default にしない。

- [Walker Art Center — Flyer for Three Old Paintings of Yoko Ono](https://www.walkerart.org/collections/artwork/flyer-for-three-old-paintings-of-yoko-ono-naiqua-gallery-tokyo/)
  - Observe: mimeograph という低コスト複製 process と gallery event announcement の関係。
  - Useful for: production constraint が artifact character に影響し得る evidence。
  - Avoid copying: mimeograph/photocopy appearance を「authentic flyer」filter にしない。

## Production systems

- [Walker Art Center — Painter Painter: Exhibition Identity](https://www.walkerart.org/reader/painter-painter-exhibition-identity/)
  - Observe: 一つの exhibition identity が admission pass、gate-fold event flyer、landing page、poster、gallery guide 等へ変換されること。flyer では gate fold と translucent metallic spot が具体的な artifact behavior を持つ。
  - Useful for: key visual / identity と flyer-specific format/handling の分離、fold を information/experience structure として使う場合。
  - Avoid copying: gate fold や metallic finish を flyer の品質記号にしない。

- [Studio Dumbar — ATypI](https://studiodumbar.com/work/atypi)
  - Observe: event identity が posters、programmes、map、other collateral へ展開され、同じ system 内でも artifact ごとに情報密度と役割が異なること。
  - Useful for: event series / collateral family、programme と promotional artifact の責務差、type-led event identity。
  - Avoid copying: specific A13 mark、color clashes、type pairings を流用しない。

- [Studio Moross — Roundhouse Beyond + Between](https://www.studiomoross.com/work/beyond-between)
  - Observe: summer programme の artwork が building surfaces と promo creative の双方へ展開され、event programming と written quotes が spatial/promotional context に応じて使い分けられること。
  - Useful for: programme-level identity を flyer / promo derivative へ翻訳するときの content ownership と campaign continuity。
  - Avoid copying: queer-culture-specific visual/copy expression を unrelated event の style vocabulary にしない。

## Supporting comparison

- [Walker Art Center — Rock the Garden 2012 Graphic Identity](https://www.walkerart.org/reader/rock-the-garden-2012-graphic-identity/)
  - Observe: event mark が advertisements、ticket stock、banners、ID tags、commemorative posters へ変換され、color system は application ごとに変化しながら identity を保持すること。
  - Useful for: event-wide retained/variable rule と flyer が wider collateral family に属する場合の比較。
  - Avoid copying: moiré、stripes、dots、open color system を event identity の universal recipe にしない。

## Cross-reference questions

reference を開いたら、最低限次を比較する。

- これは遠距離 display か、hand-held / invitation / retained ephemera か
- event recognition と actionable logistics のどちらが強いか
- date / venue / programme / organizer / next step はどのように grouped されるか
- single sheet / front-back / fold / multi-piece の選択は情報量と handling にどう対応するか
- identity の retained property と event-specific variable は何か
- production process は意味を持つか、それとも単なる historical constraint か
- digital derivative に変えたとき何が失われ、何を再構成する必要があるか

reference の具体的 logo、brand asset、artist imagery、exact dimensions、color、font、print process を current project の universal rule にしない。
