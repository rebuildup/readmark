# Key Visual Design References

Last reviewed: 2026-09-14

この reference family は、一枚の代表画像の appearance を模倣するためではなく、campaign / event / title の visual proposition が複数 artifact へどう展開されるかを比較するために使う。

観察では、各 project の proprietary assets、exact colors、typefaces、commissioned imagery をコピーしない。**retained property / variable property / transformation reason** を抽出する。

## Pentagram — London Design Biennale 2018

- Primary creator source: https://www.pentagram.com/work/london-design-biennale-2018
- Official event context: https://londondesignbiennale.com/editions/london-design-biennale-2018
- Type: event campaign / visual identity

Observe:

- event theme `Emotional States` が、literal portrait ではなく commissioned paper-mask series へ翻訳されていること
- seven-emotion variation の中で、material、portrait framing、restricted palette、dark field、identity structure が family cue として働くこと
- 一つの mask を master image とせず、複数 subject が同じ proposition の variant として成立していること
- online banner / print / outdoor / social / marketing へ同じ visual world が展開されること
- campaign concept と、個々の mask の具体的 form を分離して読むこと

Useful for:

- one theme → multiple content variants
- commissioned imagery を campaign-wide carrier にする場合
- recognizable family と subject variation の両立

Avoid copying:

- orange / black / white palette
- paper masks、portrait setup、exact typography
- Darwin / emotion concept 自体

## Pentagram — London Design Festival 2018

- Primary creator source: https://www.pentagram.com/work/london-design-festival-2018
- Type: recurring event campaign

Observe:

- long-lived festival identity の中で、その年固有の visual idea を作っていること
- existing festival recognition と annual campaign expression の hierarchy
- Johnston-derived typographic intervention が poster / signage / merchandise / advertising / guide へ展開されること
- static typographic form が「ever-evolving」system として variation を許容すること
- same logo/template ではなく、campaign-year concept と parent event continuity を分離していること

Useful for:

- parent identity + temporary campaign identity
- typography-led key visual
- recurring event の年度差分

Avoid copying:

- London red、Johnston、fractured lettering
- festival 固有の cultural references

## Pentagram — London Design Festival 2019

- Primary creator source: https://www.pentagram.com/work/london-design-festival-2019
- Type: recurring event campaign

Observe:

- crowded London environment で recognition を作る目的が明示されていること
- strong italic typographic direction を、その年の identity signature として複数 campaign material に展開すること
- previous year と radically different な visual mechanism でも、festival campaign として成立すること
- parent identity と annual key visual を混同しないこと

Useful for:

- annual campaign system
- one dominant typographic proposition を多媒体へ展開する場合

Avoid copying:

- exact italic treatment、abbreviations、palette

## Studio Dumbar — D&AD Festival 2020 / Imagine Everything

- Primary creator source: https://studiodumbar.com/work/imagine-everything-d-ad
- Type: event campaign / motion / digital / print

Observe:

- positioning `Imagine Everything` が visual system より先に定義されていること
- `imagine` を recurring anchor としながら phrase/content が変わること
- variable typography が「無限の creativity」という proposition を担うこと
- physical festival 用 material が COVID-19 により digital-only experience へ移行した際、AR filter / personalized social / landing page などへ system が適応したこと
- medium が変わっても exact layout ではなく concept / behavior が連続すること

Useful for:

- concept → type behavior → multi-touchpoint transformation
- delivery environment が途中で大きく変わる campaign
- static / motion / interactive 間の identity continuity

Avoid copying:

- Marfa、stretching typography、`Imagine Everything` wording

## Studio Dumbar — Apple Football Design System

- Primary creator source: https://studiodumbar.com/work/apple
- Type: large-scale variable campaign / motion system
- Project completed: 2024

Observe:

- major football tournament 用に、一つの finished hero ではなく adaptable system を設計していること
- `Team X vs Team Y` の組み合わせを大量に生成できるよう variation logic が設計されていること
- daily content change と visual consistency を両立する rule-generated behavior
- content variant の数が増えたとき、manual one-off art direction だけでは維持できない system requirement

Useful for:

- high-volume content variants
- combinatorial / data-fed campaign family
- motion-led key visual system

Avoid copying:

- Apple assets、football-specific visual vocabulary、exact animation system

## Studio Moross — Future1000

- Primary creator source: https://www.studiomoross.com/work/future1000
- Type: campaign / branding / poster / social / merchandise
- Year: 2021

Observe:

- school notebook / folder customization という contextual idea が sticker-based toolkit へ翻訳されていること
- logo、stickers、color、graphic parts が固定 poster ではなく toolkit として client へ渡されていること
- campaign team が large variation of content を作れる flexibility
- poster / social / merchandise で同じ parts を使いながら composition を固定していないこと

Useful for:

- decentralized content production
- client-operable campaign toolkit
- modular graphic parts から family を生成する場合

Avoid copying:

- school-notebook aesthetic、sticker shapes、exact bright palette

## Studio Moross — Glitterbox 2025 Campaign Direction

- Primary creator source: https://www.studiomoross.com/work/glitterbox-2025-campaign-direction
- Type: campaign direction / photography / video / poster / billboard / social / venue visuals

Observe:

- five `muses` という campaign concept により複数人物を一つの family にしていること
- photo / video shoot の段階で posters, billboards, social, club visuals まで想定した source coverage を確保していること
- each muse が個別 aesthetic を持ちながら campaign identity に属していること
- key visual system が post-production layout だけではなく source production plan に影響すること

Useful for:

- multiple subjects / performers を一 campaign に統合する場合
- still + motion を同じ shoot/source family から展開する場合
- source planning を key visual 設計へ含める場合

Avoid copying:

- muses 自体、club aesthetic、specific wardrobe / photography / logo treatment

## Studio Moross — Jade Bird, Who Wants to Talk About Love

- Primary creator source: https://www.studiomoross.com/work/jade-bird-wwttal
- Type: album campaign / packaging / single artwork / poster
- Year: 2025

Observe:

- road-trip photography と ephemera / keepsake という narrative carrier の関係
- album artwork、single artworks、packaging、poster で同じ memory-world を使いながら artifact ごとの構成と material が変わること
- physical print では halftone / textured paper など medium-specific treatment を使うこと
- campaign concept と primary album cover が同じではないこと

Useful for:

- one source-story / image archive から multiple release assets を作る場合
- digital と physical で technique を変えながら continuity を保つ場合

Avoid copying:

- road-trip concept、mid-century ephemera treatment、exact halftone / paper choices

## Studio Dumbar — Amsterdam Sinfonietta

- Primary creator source: https://studiodumbar.com/work/amsterdam-sinfonietta
- Type: long-running identity / seasonal poster series

Observe:

- organization は recognisable なまま、poster series が season ごとに radically different になること
- individual poster が performance の musical theme へ応答すること
- durable brand recognition と campaign/season visual variation の境界
- series continuity が exact campaign appearance の永久固定を意味しないこと

Useful for:

- parent identity が長期、campaign expression が短期の場合
- campaign-to-campaign variation の許容範囲を考える場合

Avoid copying:

- individual poster style、specific type / color / graphic treatments

## Cross-reference comparison

比較するとき、次の問いを使う。

### Proposition

- 一文で何を visualized しているか
- visual carrier を別のものへ変えても proposition は説明できるか

### Recognition

- logo を隠しても family cue が残るか
- retained cue は subject / type / palette / material / composition / behavior のどこにあるか

### Variation

- content variant と format derivative はどう違うか
- variation は concept に由来するか、単なる decoration か
- high-volume variation に耐える rule があるか

### Transformation

- poster → social → wide banner → motion → physical で何が変わるか
- crop だけか、composition / hierarchy / behavior を再設計しているか

### Parent relationship

- durable brand の何を保持しているか
- campaign 固有表現はどの程度 temporary か
- annual/seasonal change をしても parent recognition は残るか

### Production reality

- source assets は derivative 用に十分か
- rights / crop / localization / motion / print constraints は system に含まれているか
- final artifacts を並べたとき、同じ campaign でありながら各 artifact の job が成立しているか
