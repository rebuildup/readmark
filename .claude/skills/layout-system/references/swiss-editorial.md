# Swiss / Editorial / Typographic References

Last reviewed: 2026-09-10

## Goal

Swiss / editorial reference では aesthetic surface を模倣するのではなく、apparently asymmetric composition を coherent に保つ invisible alignment system を観察する。

## Primary references

### Swiss Design Awards

Current site:
https://www.swissdesignawards.ch/

Observe:

- metadata / heading / visual の alignment
- typography scale contrast
- asymmetric column allocation
- whitespace
- repeated axes
- editorial list / detail structures
- image と text の shared boundaries

### Dinamo Typefaces

Production:
https://abcdinamo.com/

Catalogue:
https://abcdinamo.com/catalogue

Observe:

- filter / metadata / specimen / controls の同居
- typography を情報 hierarchy と navigation に使う方法
- dense catalog を grid と type で整理する方法
- Swiss-influenced graphic structure と tool-like interaction の交差

### Studio Feixen

Production:
https://www.studiofeixen.ch/

Observe:

- controlled grid breaking
- strong type / image scale differences
- apparently playful layout の下にある recurring edges
- whitespace と density の contrast

reference の表層的 playfulness をコピーせず、崩しても coherent である理由を見る。

### Optimo

Production:
https://optimo.ch/

Observe:

- type specimen
- glyph / metadata / commercial information
- repeated typographic alignment
- long-form information と large specimen の共存

## Supporting system reference

### IBM 2x Grid

https://www.ibm.com/design/language/2x-grid/

## Do not reduce Swiss design to

- Helvetica
- black and white
- visible grid
- equal columns
- minimal decoration

## Extraction checklist

- strongest vertical axes
- baseline / line-height rhythm
- metadata alignment
- heading scale ratio
- text measure
- image edge alignment
- repeated whitespace units
- intentional violations
- density transitions

質問は「何 columns か？」だけではない。

より重要なのは:

> unrelated elements が、どの invisible lines を繰り返し共有しているか。
