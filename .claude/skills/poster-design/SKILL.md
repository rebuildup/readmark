# Poster Design

ポスターを、単に「大きな静止画」や「キービジュアルを縦長に配置したもの」として扱わない。

ポスターは、壁面・会場・街路・店頭・掲示面・デジタル表示などで**人が遭遇する display artifact**である。遠距離や通過中の初見で何かを成立させつつ、必要なら近づいた後の二次情報も読めなければならない。

この Skill は poster 固有の encounter、first read / second read、display-scale composition、series variation、final artifact verification を扱う。細かな本文組版は `typesetting`、混植は `font-mixing`、一般的な salience orchestration は `visual-hierarchy`、時間変化は `motion-poster` に委ねる。

## When to use

次のような静的 poster artifact を設計・再設計するときに使う。

- 展覧会・公演・コンサート・映画・イベントの告知
- キャンペーンや公共メッセージの掲示物
- 店頭・施設・街路・OOH 相当の静的 display graphic
- 複数公演・複数会場・複数日程を持つ poster series
- print poster と digital poster の双方を持つ campaign derivative

次の場合は、この Skill を primary owner にしない。

- 小さな browse card で開く/見る判断を支える → `thumbnail-design`
- 音楽 release の persistent artwork → `album-cover-design`
- campaign 全体の master visual language を決める → `key-visual-design`
- 手渡し・持ち帰り前提で近距離情報量が中心 → `event-flyer`
- 時間変化・loop・途中遭遇を設計する → `motion-poster`
- wayfinding / navigation / instruction が primary job → `signage-design`

## Workflow

1. **Inspect encounter** — audience、掲示場所、物理/デジタル媒体、典型的な距離、通過速度、滞在時間、周囲の競合を確認する。
2. **Extract information jobs** — first read / second read / optional detail に情報を分ける。
3. **Compare references** — 複数ポスターを下記 observation axes で比較し、1作品の style を規則化しない。
4. **Choose communication mechanism** — image-led / type-led / text-dense / symbol-led / abstract-systemic / hybrid のどれを主軸にするか決める。
5. **Compose for encounter** — focal entry、視線経路、scale relationship、edge/crop、情報群を現在の content と placement に合わせて設計する。
6. **Resolve variants** — series、locale、venue、date、format がある場合、保持する要素と変える要素を明示する。
7. **Implement through the current system** — current brand / typography / assets / production constraints を尊重し、reference 固有 asset や exact value はコピーしない。
8. **Verify delivered poster** — authoring canvas ではなく、最終出力を距離・近接・環境・variant・export の各条件で確認する。

## Inspect: encounter before composition

制作前に最低限、次を取得する。

- 誰が見るか
- 何を認識・理解・記憶・行動してほしいか
- どこに置かれるか
- 静止して見るか、歩行/移動中に見るか
- 最初に視認できるおおよその距離と表示寸法
- 周囲に他の poster / signage / UI / architecture がどの程度あるか
- 近づいて読む必要がある情報は何か
- print / screen / raster / photograph-of-poster など、実際の delivery path
- 単品か series か
- locale / venue / date / sponsor 等の variant があるか

固定の「正しい閲覧距離」や paper size を universal rule にしない。重要なのは、**実際の遭遇条件に対して first read と second read が成立するか**である。

## Observe

### 1. Communication job

- poster の primary job は何か: identify / announce / persuade / invite / provoke / inform / commemorate
- viewer が first read で持ち帰るべきものは何か
- second read で必要な logistics / context は何か
- 行動先がある場合、URL / QR / venue / date / ticket 情報の責務はどこか

### 2. Encounter and distance

- 遠距離で残る silhouette / mass / title / symbol は何か
- 通過中の短い露出でも entry point が成立するか
- 近接時に初めて現れる detail は何か
- 周囲との競合に対して、poster 自身の境界と focal point が読めるか

### 3. First read / second read

first read と second read を「大きい文字 / 小さい文字」という二段階だけにしない。

観察する:

- 最初に目を引く element
- そこから次に読む element
- logistics がどこで拾えるか
- detail を読まなくても artifact の identity が残るか
- detail を読むと意味が深まるか、それとも単なる装飾 noise か

### 4. Dominant communication mechanism

ポスターは複数の方法で成立する。reference を次のように分類して比較する。

- **image-led** — photograph / illustration / object / figure の視覚的主役が入口
- **type-led** — title / lettering / type scale / spacing 自体が主要 image
- **text-dense** — 多量の言語情報を size / weight / direction / rhythm / grouping で視覚化
- **symbol-led** — 一つの mark / object / metaphor が認識を担う
- **abstract/systemic** — grid / shape / color / rule / generative relation が identity を担う
- **hybrid** — image/type/system が相互依存して成立

1つを universal default にしない。

### 5. Focal entry and eye routing

- entry point は中央、端、文字、顔、空白、色面、反復、切断など何で作られているか
- eye が poster 内でどの順に移動するか
- overlap / crop / edge contact が視線を止めるか進めるか
- diagonal / axis / alignment が情報順序と関係しているか
- focal element が強すぎて secondary information を永久に遮断していないか

### 6. Scale relationships

absolute font size ではなく、相対的な scale を見る。

- poster 全体に対する dominant element の面積
- primary / secondary / logistics の差
- 大きい element が単なる decoration か、意味を持つか
- small detail が close-read reward として機能するか
-縮小時に何が消え、何が残るか

### 7. Type as information / image / structure

文字の role を分ける。

- literal information
- identity / title
- visual mass
- directional device
- texture / repetition
- image と一体化した構造

文字を image として使っても、必要な情報まで読めなくしてよいことにはならない。逆に text-heavy poster を「情報が多いから失敗」と決めつけない。

### 8. Density and grouping

- copy volume は encounter に対して妥当か
- high-density の場合、どの alignment / weight / spacing / direction / grouping が routing を作るか
- logistics は一つの block にまとめるか、composition 内へ分散するか
- dense information が intentional texture と legible content の双方を担っているか

### 9. Grid, axis, and controlled break

- grid が clarity / recurrence / series consistency を何に使っているか
- grid を外れる element が何を強調しているか
- strict alignment と expressive break のどちらが content に合うか
- reference の grid dimension を magic number としてコピーしない

### 10. Color, contrast, surface, material

- color が hierarchy / category / atmosphere / series identity のどれを担うか
- paper / ink / risograph / overprint / emboss / texture / photographic surface が concept に関係するか
- material effect がなくなった digital/raster variant でも主読解が成立するか
- process artifact を単なる “vintage effect” として再現していないか

### 11. Series continuity

series では毎回同じ template に固定しない。

各 variant について記録する。

- **retained** — identity のため維持するもの
- **changed** — content / season / venue / performer / theme に応じて変えるもの
- **reason** — その差が viewer の区別や内容理解にどう効くか

series は「同じに見える」だけでなく、**同じ family と認識でき、個々も区別できる**必要がある。

### 12. Localization / venue adaptation

- translated title / Japanese-Latin mixed text / venue / date / sponsor が hierarchy を変えるか
- translation 追加後も first read が同じである必要があるか、local audience に合わせて変更すべきか
- 文字量の増減を縮小だけで吸収していないか
- venue ごとの情報差を composition の変数として扱っているか

reference の localized variant が元版と異なる構成を採用していても、それを degradation と決めつけない。

## References

実行時は [`references/poster-design.md`](./references/poster-design.md) を開き、task に近い reference family を複数比較する。

最低でも次を混ぜる。

- poster mechanics / established analysis
- canonical historical artifact
- production poster system / series
- task に応じて current campaign / localized variant

## Decision rules

### Rule 1: Encounter before canvas

format を見てから composition recipe を選ばない。誰がどの距離・速度・環境で遭遇するかを先に決める。

### Rule 2: Define first and second read explicitly

少なくとも次を文章化する。

- first read: `<viewer should get ...>`
- second read: `<viewer can then get ...>`
- optional detail: `<only if closer/longer viewing ...>`

すべてを first read に押し込まない。逆に essential logistics を decorative microtype に落とさない。

### Rule 3: Choose a mechanism, not a style label

`bold`, `Swiss`, `punk`, `clean`, `experimental` のようなラベルだけで direction を決めない。

代わりに、何が視線を捕まえ、どの関係で hierarchy が生まれるかを指定する。

例:

- oversized type + asymmetric edge crop
- one symbolic object + restrained logistics block
- dense multi-weight type field + one recurring alignment axis
- repeated geometric module + controlled exception

これらも fixed recipes ではなく、現在の content に対する hypothesis とする。

### Rule 4: Do not equate minimal copy with good poster design

Public Theater のように大量情報を expressive hierarchy に組み込む poster も成立する。copy を削る判断は、poster encounter と information job から行う。

### Rule 5: Do not universalize the central-image formula

一つの中央 image は有効な場合もあるが、それ自体を poster grammar としない。content、entry point、surroundings、secondary information との関係で選ぶ。

### Rule 6: Separate key visual from poster adaptation

campaign master asset があっても、poster では viewing distance、format、local logistics、surface に合わせて再構成する。

key visual の存在を、poster composition を考えない理由にしない。

### Rule 7: Preserve family by invariants, not cloning

series の identity は exact layout repeat ではなく、type family、mark、color behavior、alignment logic、image treatment、recurring module 等から必要な invariant を選ぶ。

### Rule 8: Verify physical and digital behavior separately when both exist

print process に依存する depth / texture / overprint があるなら、その効果を print で確認する。digital delivery では同じ physical illusion を偽装するのではなく、必要な first read / identity を別 representation でも成立させる。

### Rule 9: Compare materially different directions when the mechanism is unclear

判断が曖昧なら、minor color variant を並べない。

例:

- type-led vs image-led
- sparse single-symbol vs dense information field
- strict grid vs intentionally broken axis

のように communication mechanism 自体が異なる案を比較する。

## Avoid

- hero image を中央に置き、その上下へ title/date を置くだけの自動 template
- headline を極端に大きくすれば poster になるという判断
- 全情報を等しく見せること
- 逆に、minimal に見せるため essential information を消すこと
- reference の grid、font size、margin、palette をそのまま移植すること
- one creator / one historical movement の特徴を poster 全般の rule にすること
- poster series を同じ template の色違いだけにすること
- localized text を最後に縮小して押し込むこと
- paper texture / halftone / grain を意味なく “poster-like” に足すこと
- mockup だけ見て完成とすること
- key visual、album cover、thumbnail を crop しただけで poster とすること
- print 用 effect を screen screenshot だけで評価すること

## Verify

source file / renderer success ではなく、**delivered poster** を確認する。

### 1. Distance / reduction proxy

実掲示距離を再現できる場合は実物で見る。できない場合は calibrated reduction / viewport proxy を使う。

確認する:

- first read が何か説明せずとも現れるか
- silhouette / major mass / title / symbol が埋没しないか
- surrounding visual noise の中でも境界と入口が分かるか

### 2. Close read

100% / intended print size 相当で確認する。

- date / venue / names / CTA / sponsor / legal 等が必要な精度で読めるか
- secondary information の grouping が追えるか
- micro detail が accidental noise になっていないか

### 3. Representative environment

可能なら実 placement、なければ代表的な environment mock/context へ置く。

ただし mockup の質を poster の質と混同しない。

確認する:

- 壁色 / 周囲 poster / frame / screen bezel / architecture で hierarchy が壊れないか
- viewing angle や glare が重要なら実条件で再確認する

### 4. Variant / series

series がある場合、最低3点程度を並べる。

- family として認識できるか
- individual content が区別できるか
- retained / changed property に説明可能な理由があるか

### 5. Localization / long-content

該当する場合、実 locale と最長現実的 content で render する。

- mixed Japanese/Latin
- longer translated title
- venue/date differences
- sponsor count changes

### 6. Physical output

print が delivery の中心なら、可能な限り実寸または production-representative proof を確認する。

- crop / trim / edge interaction
- type/image sharpness
- material/process effect
- dark/light area の潰れ
- intended viewing distance

prepress 操作手順そのものはこの Skill の source of truth にしない。

### 7. Final raster / digital output

screen/digital derivative もある場合、最終 encode / raster で確認する。

- scaling artifacts
- compression
- small text
- color shift
- texture disappearance
- aspect-ratio adaptation

### 8. Artifact trial gate

promotion 前に実案件相当の trial を最低1回行う。

1. real brief / actual copy / approved assets を使う
2. encounter と first/second read を記録する
3. direction が自明でなければ materially different な2案以上を比較する
4. final-size/distance proxy と close read を確認する
5. representative environment へ置く
6. required variants / localization / series を確認する
7. delivered print proof または final raster/export を inspection する
8. failure と revision を Issue / PR に durable に残す

この trial が終わるまでは first-class promotion 完了と偽らない。
