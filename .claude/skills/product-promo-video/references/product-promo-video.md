# Product Promo Video References

Last reviewed: 2026-09-14

このreference familyは product film のvisual styleをコピーするためではなく、**claimを何で証明し、どこまでliteral / abstractに扱うか**を比較するために使う。

同一studioの表現だけを一般化しない。物理product、UI/compute、不可視mechanism、sensorial productで異なるevidence modelを比較する。

## First-party product claim source

### Apple — Introducing iPhone Air

https://www.apple.com/newsroom/2025/09/introducing-iphone-air-a-powerful-new-iphone-with-a-breakthrough-design/

Observe:

- product claim hierarchy: thin/light/strong, camera, silicon/performance, battery
- physical-detail evidenceとusage/result evidenceの違い
- whole-product / side profile / internal architecture / camera resultの役割分担
- quantified claimがどのcontextと組み合わされているか

Useful for:

- approved product factsからfilm proofを逆算する
- geometry / physical form / feature / resultを別evidenceとして扱う

Avoid copying:

- Apple固有のbrand hierarchy、camera language、type、product rendering
- comparative / quantified claims without an approved source

## Cross-reference comparison

複数referenceを開いたら、最低限次を比較する。

| Axis | Questions |
| --- | --- |
| Claim | 何をviewerに信じてほしいか |
| Evidence | 何がそのclaimを実際に支えているか |
| Truth level | literal / demonstrated / simulated / abstracted / sensorial のどれか |
| Anchor | productとの関係を何が保つか |
| Causality | input / mechanism / outputが追えるか |
| Detail | macro/detailは何を証明するか |
| Whole | whole-product/contextへいつ戻るか |
| Text | visual proofを補足しているか、代替しているか |
| Motion | camera/effectsがproofを明確化するか隠すか |
| Modularity | one hero storyかfeature module群か |
| Delivery | crop / compression後もfeature detailが残るか |

## Failure patterns to recognize

- productをほとんど見せず、abstract worldだけでfeatureを説明したつもりになる
- technical visualizationのinput / output / product locationが不明
- specをsuperで表示するだけでvisual evidenceがない
- concept UIやaccelerated workflowをactual behaviorのように見せる
- impossible product deformation / hinge range / assembly / material behavior
- hero renderは美しいがfeature benefitとの関係がない
- macro shotが続き、viewerがproduct全体を再構成できない
- every featureが同じanimation grammarで扱われ、priorityが消える
- metaphorが強すぎてclaimよりcampaign motifが記憶される
- final compressionでscreen text / thin detail / material differencesが消える

これらはstyle failureではなく、claimとevidenceの接続failureとして診断する。
