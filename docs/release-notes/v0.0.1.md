# readmark v0.0.1

readmark の初回リリースです。ローカルファーストの PDF 読書体験として、文書本体と読書状態をブラウザ内に保持し、再読時に前回の状態へ戻れる MVP を提供します。

## 主な機能

- ローカル PDF の import と IndexedDB への保存
- ライブラリからの再オープン
- PDF の閲覧
- 最終閲覧ページ・位置の保存と復元
- 栞の追加・削除と一覧からのジャンプ
- PDF テキスト選択
- 選択範囲へのハイライト
- ハイライトへのメモ
- 栞・ハイライト・メモの一覧表示
- PDF annotation anchor の保存と再アンカー
- pdf.js support tables（CMap / standard fonts / wasm / ICC）の配信

## データモデル

- `Document` / `DocumentSource` / `DocumentBlob` を分離
- 位置を持つ読書状態を `DocumentId` と `SourceFingerprint` の組で管理
- 永続化は IndexedDB / Dexie に限定
- PDF 固有実装を `src/reader/pdf/` に隔離

## リリース前レビューで修正した問題

- 未描画ページへの復元後、上段ページの実寸化で scroll 位置が再びずれる問題
- 旧 IndexedDB recovery が delete の error / blocked を成功扱いする問題
- Windows の Vite dev server で pdf.js support tables が 404 になる path containment 問題
- 選択範囲から作った栞が作成直後の bookmarks panel に表示されない問題

## 検証

## 対象外

このリリースには、クラウド同期、アカウント、EPUB / Markdown / text、AI 機能、テレメトリ、my-web-2026 との統合方式固定は含みません。
